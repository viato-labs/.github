# Ticket Flow Agent (Chrome)

Chrome MV3 side-panel agent that drafts and creates Jira tickets using your **logged-in browser session**.

## Load unpacked

1. `chrome://extensions` → Developer mode → Load unpacked
2. Choose this folder: `chrome-extension/`
3. Open company Jira → click the extension icon

See [`../docs/CHROME_AGENT.md`](../docs/CHROME_AGENT.md).
